# T7.M2 Coding Interviews

Quantum coding interviews reuse a small set of patterns, and the fastest route through a loop is recognising which one a prompt is asking for. The first lesson enumerates fifteen, each with its canonical problem and the resource bound an interviewer expects a candidate to volunteer. Three timed labs follow, graded on hidden tests against a clock: build a three-qubit state carrying a relative minus sign within two two-qubit gates, implement a Bernstein-Vazirani phase oracle with no ancilla and no two-qubit gate, and construct an exact three-qubit quantum Fourier transform inside a stated gate budget.
