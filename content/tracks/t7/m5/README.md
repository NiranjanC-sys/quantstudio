# T7.M5 Portfolio

Evidence beats claimed familiarity. This module produces two artefacts. The first is a reviewable contribution to Qiskit, Cirq or PennyLane, which means finding the contribution guide, the issue labels and the test command, then writing a bug report that carries a minimal reproducing circuit and the observed against the expected statevector. The second is a published result whose numbers survive contact with a stranger: pinned versions, backend name and calibration timestamp, estimates reported with shot-derived error bars, and raw counts, analysis code and seeds packaged so that the figure regenerates unaided.
