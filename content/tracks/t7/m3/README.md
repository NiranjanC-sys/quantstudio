# T7.M3 System-Design Interviews

System-design loops at quantum companies ask about scheduling, calibration, cost and failure far more often than about algorithms. The first lesson enumerates fifteen recurring prompts, each paired with the constraint it turns on, and fixes an answer structure: requirements, interfaces, data path, failure modes, cost. The lab makes one slice of that design concrete and gradeable, choosing the lowest-error contiguous chain from a calibration table and emitting a GHZ state on exactly those physical qubits. The checkpoint turns the rubric back on the learner, scoring a recorded answer and naming the failure-mode analysis that was left out.
