# T7.M4 Company Briefings

Twenty employers, each reduced to the four facts an interview turns on: which qubit modality they build or target, which SDK their code is written in, what their loop actually asks, and which primary documentation to read the night before. The briefings separate employers who interview on device physics from those who interview on compilation and software engineering, which changes what preparation is worth doing. The drill converts the briefings into spaced-repetition prompts, so the modality, the SDK and the one distinguishing interview topic stay recallable from the company name alone.
