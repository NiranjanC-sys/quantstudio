# T7.M6 Capstone

One project, defended. The capstone asks for a reproducible result rather than a working notebook: pinned software versions, a recorded backend and calibration timestamp, raw counts retained, and a claim stated with an error bar derived from the shot count. Scope is graded as heavily as execution, which means naming the classical baseline that was not beaten and saying exactly which regime the result covers. Two reviewers question the claim, and the learner in turn reviews two peer submissions against the published rubric, filing written feedback a submitter could act on.
