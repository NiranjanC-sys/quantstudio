Deferred measurement says you never *have* to measure in the middle. This lesson
is about why you would want to anyway. The answer is that a measured qubit can be
returned to $\ket{0}$ and used again, and on a device where qubits are the
scarcest thing you own, a circuit that reuses one wire twice is a circuit that
fits.

## Reset is not a gate

Every operation in T1.M3 was unitary, which means invertible: given the output
state you can recover the input. Reset is the first operation in this track that
is not.

$$
\mathrm{reset}: \ket{0} \mapsto \ket{0}, \qquad \ket{1} \mapsto \ket{0}.
$$

Two different inputs, one output. No matrix does that, because a matrix with two
equal columns has determinant zero and cannot be unitary. Physically, reset is
implemented as a measurement followed by an $X$ conditioned on the outcome, which
is precisely the classically controlled construction from the previous lesson:

$$
\text{measure } q \to c, \qquad \text{then } X \text{ on } q \text{ if } c = 1.
$$

The information did not disappear. It moved into the classical bit, and if you
throw that bit away the operation is irreversible in the thermodynamic sense you
met in T0.M6.L3.

<Margin label="Why it must be non-unitary">
Reset takes a two-dimensional space onto a one-dimensional one. Any operation
that reduces the dimension of the reachable set destroys information, and no
unitary does that. Reset, measurement and decoherence are the only three
non-unitary things in this whole track.
</Margin>

<Callout tone="gotcha" title="Reuse is not free">
The single-wire version trades width for depth, and depth is time, and time is
decoherence. Reuse pays off when the alternative is not running at all. It is a
loss when you had the qubits anyway.
</Callout>

## Where reuse actually shows up

Three patterns in the rest of the curriculum depend on this lesson, and it is
worth naming them now so the technique does not look like a toy.

**Syndrome extraction.** Every error-correcting code in T4 measures ancilla
qubits repeatedly, round after round, and resets them between rounds. A surface
code that allocated a fresh ancilla per round would need a new qubit every
microsecond forever.

**Repeat until success.** Some gate constructions are probabilistic: they apply
the intended operation when a measured flag comes out 0, and a known recoverable
error otherwise. The circuit measures the flag, resets the ancilla, and tries
again. Without reset the ancilla count would grow with the number of attempts.

**Qubit-count reduction in simulation.** A circuit that measures a register and
never uses it again can free those wires for the next stage. On a device with 5
usable qubits this is the difference between running and not running.

## The latency you are actually paying

Gate times and measurement times are not the same order of magnitude. On
superconducting hardware a single-qubit gate takes tens of nanoseconds and a
two-qubit gate a few hundred. A projective readout takes on the order of a
microsecond, because it has to integrate a weak signal for long enough to
separate two distributions with confidence.

That gap is the first cost. The second is the classical round trip. A mid-circuit
measurement whose result controls a later gate requires the outcome to be
digitised, routed to the controller, tested against a condition, and turned back
into a pulse. During all of it the other qubits idle, and idling is not free: a
qubit accumulates relaxation and dephasing whether or not you are doing anything
to it, which is the subject of T1.M11.

So the practical rule is not "avoid mid-circuit measurement", it is: know which
resource is binding. If it is width, reuse. If it is coherence time, defer.

<Check question="A colleague replaces a reset with an $X$ gate conditioned on nothing, arguing that it returns $\ket{1}$ to $\ket{0}$. When does this fail?">
Whenever the qubit was not in $\ket{1}$. An unconditional $X$ maps $\ket{0}$ to
$\ket{1}$, so it only works if you already know the qubit is in $\ket{1}$, which is
the one case where you did not need a reset. On a superposition it fails worse
than that: $X\ket{+} = \ket{+}$, so the qubit is left in the state you were trying
to clear. Reset needs the measurement, because the measurement is what supplies
the knowledge that decides whether the flip should happen.
</Check>
