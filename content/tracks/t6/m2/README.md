# T6.M2 Coherence and Control

Coherence is the budget every circuit spends. This module separates T1, the energy-relaxation constant, from T2 and T2 star, which describe the loss of phase information, and fixes the inequality between them. Ramsey and Hahn echo sequences supply the measurements, and the gap between what they report identifies quasi-static noise. Control comes next: DRAG pulse shaping suppresses leakage in a weakly anharmonic qubit, a virtual Z gate is a frame update rather than a physical rotation, and shorter pulses trade duration against leakage. The module closes on crosstalk, where a gate's error depends on a neighbour that is doing nothing at all.
