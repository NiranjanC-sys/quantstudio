# T6.M5 Cloud QPU Systems

A QPU becomes a product only once a control plane surrounds it. This module covers that layer: queueing policies and why fair share matters when one user submits thousands of jobs, sessions that hold a device for an iterative variational loop, the units a provider meters, and the cost arithmetic of a many-term expectation value. Multi-tenancy raises crosstalk and side-channel questions that classical isolation vocabulary does not cover. Routing becomes calibration-aware because the best layout changes between cycles, and the last lesson treats failure as ordinary: qubits go offline, calibrations fail, and results that straddle a recalibration must be tagged or discarded.
