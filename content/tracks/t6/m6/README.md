# T6.M6 Quantum Networking

Entanglement between separated nodes is generated, not transmitted, and that distinction organises the module. Heralded schemes announce success through a detection event, and raw rates fall exponentially with fibre length, which is why repeaters exist at all. Entanglement swapping at intermediate nodes extends reach, and a useful repeater memory must hold a state for longer than a classical signal takes to arrive while writing and reading it efficiently. The module closes on the layered stack proposed for a quantum internet, where a link layer offers robust entanglement between neighbours on request and applications are classified by the network capability each one demands.
