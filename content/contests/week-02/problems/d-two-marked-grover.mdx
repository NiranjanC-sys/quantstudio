Grover's algorithm is usually taught as an approximation: run about
$\tfrac{\pi}{4}\sqrt{N/M}$ iterations, accept a success probability slightly
below 1, and repeat if unlucky. That is the general case. For a few small
$(N, M)$ pairs the rotation angle divides $\pi/2$ exactly and the algorithm is
not approximate at all. This is one of them, and finding it is a matter of
arithmetic rather than luck.

## Task

There are $N = 8$ basis states on three qubits, and $M = 2$ of them are marked:
$\ket{010}$ and $\ket{101}$. Return a three-qubit circuit that starts from
$\ket{000}$ and ends holding all of its probability on the marked pair:

$$
\ket{\psi} = \tfrac{1}{\sqrt 2}\left(\ket{010} + \ket{101}\right)
$$

up to a global phase, using **one** Grover iteration.

## Input and output contract

Implement one function, taking no arguments:

```python
def solve() -> dict:
    """Return a RedQuant circuit IR, version 1."""
```

Ops are applied in list order. This problem allows a three-wire diagonal gate,
written with all three wires in `targets`:

```python
{"id": "accz", "gate": "ccz", "targets": [0, 1, 2]}
```

`ccz` applies $(-1)^{x_0 x_1 x_2}$, so it flips the sign of $\ket{111}$ and
nothing else. To flip the sign of some other basis state, conjugate it with $X$
gates on the wires that should read 0 in that state.

Qubit 0 is the most significant bit, so the marked string $010$ means qubit 0
reads 0, qubit 1 reads 1 and qubit 2 reads 0.

## Worked example

The Grover rotation angle is $\theta = 2\arcsin\sqrt{M/N} = 2\arcsin\tfrac12 = \pi/3$,
and after $k$ iterations the probability on the marked subspace is
$\sin^2\!\big((2k+1)\theta/2\big)$. Evaluate it rather than quoting the
asymptotic form:

| $k$ | probability |
| --- | --- |
| $0$ | $0.25$ |
| $1$ | $1.0$ |
| $2$ | $0.25$ |

One iteration is not a rounding of $\tfrac{\pi}{4}\sqrt{8/2} = 1.5708$. It is
exact, and a second iteration walks all the way back to where you started.
Running the reference solution gives:

```text
|010> -0.707107 probability 0.5
|101> -0.707107 probability 0.5
```

Both marked amplitudes come out negative, which is a global phase of $-1$ and is
accepted.

## Constraints

- `qubits` is exactly 3 and `clbits` is exactly 0. No ancilla.
- At most **three** gates touching three wires at once, which is two for the oracle and one for the diffusion operator. That budget permits exactly one iteration.
- Circuit depth at most 12.
- Allowed gates: `h`, `x`, `z`, `s`, `sdg`, `cz`, `ccz`, and `x` carrying one or two controls.
- No `measure`, no `reset`, no classical conditions.

## Qiskit implementation

Your `solve` is in scope. This is the exact translation the judge uses:

```python
from qiskit import QuantumCircuit
from qiskit.circuit.library import standard_gates as sg
from qiskit.quantum_info import Statevector

NAMES = {"ccz": sg.CCZGate, "h": sg.HGate, "x": sg.XGate}

def build(ir):
    """RedQuant IR -> Qiskit. Wire q becomes Qiskit wire n-1-q, because qubit 0
    is our most significant bit and Qiskit's least. With that one change the
    amplitude arrays line up index for index."""
    n = ir["qubits"]
    w = lambda q: n - 1 - q
    qc = QuantumCircuit(n)
    for op in ir["ops"]:
        g = NAMES[op["gate"]](*op.get("params", []))
        controls = op.get("controls", [])
        if controls:
            g = g.control(len(controls))
        qc.append(g, [w(q) for q in controls + op["targets"]])
    return qc

sv = Statevector(build(solve())).data
for i, amp in enumerate(sv):
    if abs(amp) > 1e-9:
        print(f"|{i:03b}>", round(amp.real, 6), "probability", round(abs(amp) ** 2, 6))
```

Output:

```text
|010> -0.707107 probability 0.5
|101> -0.707107 probability 0.5
```
