The Steane code is the $[[7,1,3]]$ CSS code built from the classical $[7,4,3]$
Hamming code, and it is the smallest code where transversal Clifford gates all
work. Everything about it starts with one state: the logical zero. Prepare that
badly and every downstream claim about fault tolerance is void, so it is worth
knowing that the preparation is not a quantum problem at all. It is classical
coding theory, transcribed.

## Task

Return a seven-qubit circuit that starts from $\ket{0000000}$ and produces

$$
\ket{0_L} = \frac{1}{\sqrt 8}\sum_{c \in \mathcal{C}} \ket{c},
$$

the uniform superposition over the eight codewords of the even-weight subcode
$\mathcal{C}$, using at most nine CNOTs and no other two-qubit gate.

The subcode is spanned, with qubit 0 first, by

$$
g_1 = 1010101, \qquad g_2 = 0110011, \qquad g_3 = 0001111 .
$$

## Input and output contract

Implement one function, taking no arguments:

```python
def solve() -> dict:
    """Return a RedQuant circuit IR, version 1."""
```

Ops are applied in list order. A CNOT is an `x` gate carrying one control:

```python
{"id": "c0t2", "gate": "x", "targets": [2], "controls": [0]}
```

Qubit 0 is the most significant bit, so a codeword written as a seven-character
string has its first character on qubit 0, matching the generators above.

## Worked example

Read the three generators as a classical encoder. Qubits 0, 1 and 3 are the free
positions, one per generator, since $g_1$ is the only generator with a 1 in
position 0, $g_2$ the only one with a 1 in position 1, and $g_3$ the only one
with a 1 in position 3. Every other position is a parity of the free bits:

| target | fed by | from generators |
| --- | --- | --- |
| qubit 2 | qubits 0 and 1 | $g_1, g_2$ |
| qubit 4 | qubits 0 and 3 | $g_1, g_3$ |
| qubit 5 | qubits 1 and 3 | $g_2, g_3$ |
| qubit 6 | qubits 0, 1 and 3 | $g_1, g_2, g_3$ |

So the circuit is a Hadamard on each free qubit, putting the three information
bits into superposition, then one CNOT per 1 in the generator matrix outside the
free columns. That is $3 + 3 + 3 = 9$ CNOTs. Running it gives:

```text
8 codewords, each with amplitude 0.353553
['0000000', '0001111', '0110011', '0111100', '1010101', '1011010', '1100110', '1101001']
```

Every codeword has even weight, and the seven nonzero ones all have weight
exactly 4, so any two of the eight differ in exactly four positions. Each
amplitude is $1/\sqrt 8 = 0.353553$. The circuit has 12 ops, depth 6 and nine
two-qubit gates.

## Constraints

- `qubits` is exactly 7 and `clbits` is exactly 0. No ancilla, no flag qubits.
- At most nine two-qubit gates.
- Allowed gates: `h` and `x` carrying a single control. Nothing else.
- No `measure`, no `reset`, no classical conditions.

## Scoring

400 points for the first accepted submission. The judge runs
`statevector_equals` against the eight codeword amplitudes with
`up_to_global_phase` set to true and a tolerance of $10^{-9}$, then
`resource_bound` with `max_two_qubit_gates` of 9 and `max_qubits` of 7, then
`gate_set_subset` with `allowed` set to `["h", "x"]`. Getting the right eight
codewords with a relative sign anywhere among them is a rejection: $\ket{0_L}$ is
the all-plus combination, and any other sign pattern is a different logical
state. No partial credit, one penalty minute per rejected submission.

## Qiskit implementation

Your `solve` is in scope. This is the exact translation the judge uses:

```python
from qiskit import QuantumCircuit
from qiskit.circuit.library import standard_gates as sg
from qiskit.quantum_info import Statevector

NAMES = {"h": sg.HGate, "x": sg.XGate}

def build(ir):
    """RedQuant IR -> Qiskit. Wire q becomes Qiskit wire n-1-q, because qubit 0
    is our most significant bit and Qiskit's least. With that one change the
    amplitude arrays line up index for index."""
    n = ir["qubits"]
    w = lambda q: n - 1 - q
    qc = QuantumCircuit(n)
    for op in ir["ops"]:
        g = NAMES[op["gate"]](*op.get("params", []))
        controls = op.get("controls", [])
        if controls:
            g = g.control(len(controls))
        qc.append(g, [w(q) for q in controls + op["targets"]])
    return qc

sv = Statevector(build(solve())).data
words = [format(i, "07b") for i, amp in enumerate(sv) if abs(amp) > 1e-9]
print(len(words), "codewords, each with amplitude", round(sv[0].real, 6))
print(words)
```

Output:

```text
8 codewords, each with amplitude 0.353553
['0000000', '0001111', '0110011', '0111100', '1010101', '1011010', '1100110', '1101001']
```
